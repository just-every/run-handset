Handset is being built into a complete business phone system and cloud contact center for US businesses of 5 to 200
people. Today's code is its foundation. This page says which is which, so you know what you can use now.

## What you can use today

- **Your own installation.** One line starts Handset on your computer, with its own database. See
  [Getting started](/docs/getting-started).
- **Owner sign-in.** Native email sign-in with single-use links, sessions that end after seven days, and sign-out
  that ends the session everywhere. See [Sign in and sign out](/docs/sign-in).
- **First-run setup and the Lobby.** The owner confirms the installation before using it; the front page shows only
  whether setup is finished.
- **Back up and restore.** The whole installation saves to one archive and restores into an empty one. See
  [Back up and restore](/docs/backup).

## What is being built

The phone system itself is not in the code yet: numbers and porting, caller ID, the call-flow builder, desk phones
and apps, texting, recording, queues, callbacks and the AI receptionist are all clauses of Handset's contract, each
marked missing until code and tests prove it.

The [contract page](/contract) lists every clause, groups them by area and shows how many are done, partial and
missing. It is judged from the code and tests, not from plans, and changes as the code does.

## Where the homepage fits

The homepage at run-handset.com shows the product Handset is being built into, on one Monday at nine US businesses.
The businesses, people and numbers on it are an example, and the contract page is the record of what runs today.
